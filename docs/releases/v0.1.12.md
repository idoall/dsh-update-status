<h3 id="cn-v0.1.12">插件 0.1.12 — 声明兼容 DeepSeek Harness 0.2.0-rc.2</h3>

一次纯声明性更新：把 `0.2.0-rc.2` 加入已验证清单，去掉界面上那条「尚未验证兼容」的提示。代码零改动。

兼容的最新 DSH 版本：`0.2.0-rc.2`；清单里还保留 `0.2.0-rc.1` 和更早的 `0.1.7` 系列。

### ⚠️ 调整

- **跟随 `latest` 时不再看到「尚未验证兼容」**：以前即使运行的就是最新的 `0.2.0-rc.2`，界面也会把它标成未验证；现在这条提示消失。
- **兼容范围没有改动**：新版 DSH 本来就在声明范围内，不会在加载时被拒绝。
- **已在真实的 `0.2.0-rc.2` 上实测**：侧栏芯片显示 `0.2.0-rc.2` 与绿色「已是最新」，详情面板和「设置 → 版本与更新」都正常。

### 升级

```sh
dsh plugin --profile web add dsh-update-status@latest
```

装好后刷新 Web GUI 即可。

<h3 id="en-v0.1.12">Plugin 0.1.12 — declares compatibility with DeepSeek Harness 0.2.0-rc.2</h3>

A declaration-only release: `0.2.0-rc.2` joins the verified list and the *not verified compatible* advisory goes away. No code changed.

Verified against DSH `0.2.0-rc.2`; the list also keeps `0.2.0-rc.1` and the earlier `0.1.7` releases.

### ⚠️ Changed

- **No more "not verified compatible" while following `latest`.** Even on the newest `0.2.0-rc.2` the UI used to flag the running version as unverified; that advisory is now gone.
- **The compatibility range did not change** — the new DSH was already inside it, so nothing is refused at load.
- **Checked on a real `0.2.0-rc.2`**: the sidebar chip showed `0.2.0-rc.2` with the green up-to-date dot, and both the detail panel and Settings → Version & updates worked.

### Upgrade

```sh
dsh plugin --profile web add dsh-update-status@latest
```

Refresh the Web GUI afterwards.
