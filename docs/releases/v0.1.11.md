<h3 id="cn-v0.1.11">插件 0.1.11 — 声明兼容 DeepSeek Harness 0.2.0-rc.1</h3>

一次纯声明性更新：放宽插件接受的 DSH 版本范围，让它能跟着 DSH 0.2.0 一起用下去。代码没有任何改动。

兼容的最新 DSH 版本：`0.2.0-rc.1`；已验证清单里还保留更早的 `0.1.7` 系列。

### ⚠️ 调整

- **放宽了能用的 DSH 版本上限**：以前只声明到 `0.2.0` 之前，DSH 0.2.0 正式版一旦发布，本插件会在加载时被静默丢弃；现在放宽到 `0.3.0` 之前。
- **声明兼容 `0.2.0-rc.1`**：已在正在运行 0.2.0-rc.1 的实例上确认可用。
- **界面和行为没有任何变化**：侧栏芯片、详情面板、设置项都和以前一样，升级不需要迁移。

### 升级

```sh
dsh plugin --profile web add dsh-update-status@latest
```

装好后刷新 Web GUI 即可，不用改任何配置。

<h3 id="en-v0.1.11">Plugin 0.1.11 — declares compatibility with DeepSeek Harness 0.2.0-rc.1</h3>

A declaration-only release: the DSH versions this plugin accepts are widened so it keeps working once DSH 0.2.0 ships. No code changed.

Verified against DSH `0.2.0-rc.1`; the verified list also keeps the earlier `0.1.7` releases.

### ⚠️ Changed

- **A higher ceiling on the DSH versions it accepts.** The plugin used to stop before `0.2.0`, so DSH 0.2.0 stable would have silently dropped it at load; it now accepts everything before `0.3.0`.
- **`0.2.0-rc.1` is declared compatible**, confirmed on an instance already running it.
- **Nothing in the interface or behaviour moved** — the sidebar chip, the detail panel and the settings entries are as before, and no migration is needed.

### Upgrade

```sh
dsh plugin --profile web add dsh-update-status@latest
```

Refresh the Web GUI afterwards; there is nothing to configure.
