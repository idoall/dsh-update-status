<h3 id="cn-v0.1.11">插件 0.1.11 — 声明兼容 DeepSeek Harness 0.2.0-rc.1</h3>

**兼容的最新 DSH 版本：`0.2.0-rc.1`**（已验证清单同时保留 `0.1.7-rc.2`、`0.1.7-rc.1`、`0.1.7-alpha.2`）。

### ⚠️ 调整

- `dsh.engines.dsh` 与 `@deepseek-ai/dsh-settings` peer 上界从 `<0.2.0` 放宽到 `<0.3.0`——裸 `<0.2.0` 不含 DSH `0.2.0` 正式版，届时 profile 加载会静默丢弃本插件。
- 已验证清单（`dshReleases` / `VERIFIED_DSH_VERSIONS`）新增 `0.2.0-rc.1`，已在运行中的 0.2.0-rc.1 实例上验证。

### 📝 说明

- 仅声明与文档，代码零改动；118 个测试全绿，无需迁移。

### 升级

```sh
dsh plugin --profile web add dsh-update-status@latest
```

<h3 id="en-v0.1.11">Plugin 0.1.11 — declares compatibility with DeepSeek Harness 0.2.0-rc.1</h3>

**Newest verified DSH: `0.2.0-rc.1`** (the list keeps `0.1.7-rc.2`, `0.1.7-rc.1`, `0.1.7-alpha.2`).

### ⚠️ Changed

- Upper bounds of `dsh.engines.dsh` and the `@deepseek-ai/dsh-settings` peer widen from `<0.2.0` to `<0.3.0` — a plain `<0.2.0` excludes the DSH `0.2.0` stable, which would silently drop the plugin at profile load once it ships.
- The verified list (`dshReleases` / `VERIFIED_DSH_VERSIONS`) adds `0.2.0-rc.1`, verified on the running instance.

### 📝 Notes

- Declarations and docs only, zero code; all 118 tests pass, no migration needed.

### Upgrade

```sh
dsh plugin --profile web add dsh-update-status@latest
```
