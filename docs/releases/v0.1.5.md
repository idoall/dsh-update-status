<h3 id="cn-v0.1.5">插件 0.1.5 — 状态改由一颗圆点表达</h3>

换了状态的表达方式：版本芯片不再为了宣布有更新而改变底色，全部状态交给版本号旁边的一颗圆点——已是最新是绿点，检查中是灰点呼吸，有新版本是带光晕的橙色呼吸点；只有真的读不出状态才把芯片涂红。

已验证 DSH `0.1.6-alpha.2`（同时覆盖 `0.1.6-alpha.1`、`0.1.5-rc.1`）。

### 🐛 修复

- **升级 DSH 后芯片变红，是误报**：把 DSH 升到比插件已验证清单更新的版本时，插件过去把「这个预览版还没验证过」当成读取失败，整个芯片变红。现在这类提示只留在面板里，不再改变芯片颜色。
- **浅色主题下鼠标悬停芯片不再几乎消失**：以前悬停只会把底色提亮，浅色外壳下会一路推到接近纯白。

### 🎨 优化

- **新增绿色「已是最新」圆点**：以前没有更新时圆点跟随文字色，读起来像是熄灭的；现在是一颗不会动的绿色实心圆点，和表示「有新版本」的橙色呼吸点一眼可分。
- **芯片改成中性的灰色底**：深浅两套主题下都是灰底配主题文字色，橙色光晕不会再被白底吃掉。

### 升级

```sh
dsh plugin --profile web add dsh-update-status@latest
```

**升级后需要重启一次 `dsh web`**（宿主半边在启动时加载），然后刷新页面即可看到新圆点；只改客户端的那部分刷新页面就生效。插件依旧只读。

<h3 id="en-v0.1.5">Plugin 0.1.5 — one dot now carries the state</h3>

State is now told by a dot beside the version instead of the chip's colour: green when you are up to date, a grey pulse while checking, and an amber dot with a soft halo when a newer release exists. The chip only turns red when the state genuinely could not be read.

Verified against DSH `0.1.6-alpha.2` (also `0.1.6-alpha.1` and `0.1.5-rc.1`).

### 🐛 Fixed

- **A red chip after a DSH upgrade was a false alarm.** On a DSH newer than this plugin's verified list, the plugin treated "this preview has not been verified yet" as a failed read and painted the whole chip red. Such advisories now stay in the panel and leave the chip alone.
- **Hover no longer nearly erases the chip in the light theme.** Hover used to brighten the fill only, pushing the light-theme chip towards pure white.

### 🎨 Improved

- **A green "up to date" dot.** With nothing to do, the dot used to follow the text colour and read as switched off; it is now a flat green circle that does not move, easy to tell apart from the amber pulse that means a newer release.
- **A neutral grey chip.** Grey in both light and dark themes with the theme's own text colour, so the amber halo is no longer swallowed by a white background.

### Upgrade

```sh
dsh plugin --profile web add dsh-update-status@latest
```

**Restart `dsh web` after upgrading** (the Host half loads at startup), then refresh the page to see the new dot; client-only changes appear on a refresh. Still read-only.
