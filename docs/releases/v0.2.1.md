<h3 id="cn-v0.2.1">插件 0.2.1 — 隐藏版本芯片后，品牌行恢复 DSH 官方标志</h3>

一次外观修复：隐藏侧栏的版本芯片之后，品牌行不再是一片空白，而是回到 DSH 自己的标志。

兼容的最新 DSH 版本：`0.2.1-alpha.1`；已验证清单与 `0.2.0` 相同。

### 🐛 修复

- **取消勾选「在侧栏显示版本状态入口」后品牌行会变空白**：这是外观问题，不影响功能，也不会写入任何 DSH 文件。
- **现在隐藏芯片就把位置让回给 DSH 自己的名字和鱼标**；重新勾选，版本芯片原样回来。
- **受影响的是 `0.2.0` 及更早带这个复选框的版本**：升级后不用做别的，重开一次开关就能恢复。

### 升级

```sh
dsh plugin --profile web add dsh-update-status@latest
```

升级后请刷新 Web GUI。

<h3 id="en-v0.2.1">Plugin 0.2.1 — hiding the version chip brings DSH's own brand back</h3>

A cosmetic fix: hiding the sidebar's version chip no longer leaves the brand row blank — DSH's own mark comes back.

Verified against DSH `0.2.1-alpha.1`; the verified list is the same as `0.2.0`.

### 🐛 Fixed

- **Unchecking "Show the version-status entry in the sidebar" used to leave the brand row blank.** It is a cosmetic problem only, and no DSH file is ever written.
- **Hiding the chip now hands the spot back to DSH's own name and fish mark**; switch the entry back on and the chip returns unchanged.
- **`0.2.0` and every earlier version with that checkbox are affected.** Nothing else to do — flip the toggle once after upgrading and it is back to normal.

### Upgrade

```sh
dsh plugin --profile web add dsh-update-status@latest
```

Refresh the Web GUI afterwards.
