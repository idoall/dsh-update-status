本版验证 DSH `0.2.1-rc.3`，并修复监督服务反复启动失败时，面板无法显示原因和恢复命令的问题。

兼容 DSH `0.2.1-rc.3`；保留此前已验证的 `0.2.1-rc.2`、`0.2.1-alpha.5`、`0.2.1-alpha.4`、`0.2.1-alpha.3`、`0.2.1-alpha.1`、`0.2.0-rc.2`、`0.2.0-rc.1`、`0.1.7-rc.2`、`0.1.7-rc.1` 与 `0.1.7-alpha.2`。

<h3 id="cn-v0.4.6">⚠️ 调整</h3>

- **支持当前 DSH。** `0.2.1-rc.3` 加入已验证清单，不再显示“尚未验证兼容”。
- **重启保护和失败提示更可靠。** 后台维护或终端仍在启动时，也会提醒存在活动工作；监督服务反复启动失败时，能显示原因和仅供复制的恢复命令。不会自动执行恢复命令。
- **发布信息同步更新。** 中英文 README、版本对照表和升级示例统一更新；npm 发布包会在发布后与本次构建逐文件核对。

### 升级

```sh
dsh plugin --profile web add dsh-update-status@0.4.6
```

---

This release verifies DSH `0.2.1-rc.3` and fixes the panel losing the refusal reason and recovery commands when its supervisor repeatedly fails to start.

Compatible with DSH `0.2.1-rc.3`; retains previously verified `0.2.1-rc.2`, `0.2.1-alpha.5`, `0.2.1-alpha.4`, `0.2.1-alpha.3`, `0.2.1-alpha.1`, `0.2.0-rc.2`, `0.2.0-rc.1`, `0.1.7-rc.2`, `0.1.7-rc.1` and `0.1.7-alpha.2`.

<h3 id="en-v0.4.6">⚠️ Changed</h3>

- **Supports the current DSH.** `0.2.1-rc.3` joins the verified list instead of being shown as compatibility unverified.
- **More reliable restart protection and guidance.** Background maintenance and terminals still starting now trigger the active-work warning too. Repeated supervisor failures show their reason and copy-only recovery commands; those commands never run automatically.
- **Release information stays synchronized.** Both READMEs, the compatibility matrix and upgrade examples are updated together; the npm tarball will be checked file by file against this build after publication.

### Upgrade

```sh
dsh plugin --profile web add dsh-update-status@0.4.6
```
