<h3 id="cn-v0.4.7">插件 0.4.7 — 精简版本更新入口</h3>

### 版本对应

| 插件 | 已验证 DSH | npm |
| --- | --- | --- |
| `0.4.7` | `0.2.1-rc.3` 及此前十个已验证版本 | 本次发布，`latest` |

### 更新原因与调整

- **移除重复的「设置 → 版本与更新」菜单。** 安装插件后本来就默认显示版本状态和更新提示，点击侧栏版本芯片即可查看详情；独立设置页重复了这些功能，因此删除该菜单、页面及其专用样式和文案，让设置列表更简洁。
- **版本提示和主要操作保持不变。** 当前版本、更新提示、检查更新、升级说明、缓存时长和受保护的安全重启仍在版本芯片的详情面板中。仅属于旧设置页的侧栏显示开关和服务启动时间展示随页面一起移除；没有新增自动升级、自动重启或定时检查。
- **已有配置仍然兼容。** 不会在升级或挂载时自动改写偏好。旧 profile 若保存了 `sidebarEnabled: false`，仍会保持隐藏；把该值改为 `true` 或删除该覆盖值即可恢复默认显示。新安装无需先到设置中开启。
- **验证与文档同步。** 219 项测试、类型检查、构建和依赖防护检查通过；恢复指引渲染测试改为覆盖保留的详情面板，中英文 README 同步更新。

### 兼容性与升级

DSH 范围保持 `>=0.1.7-alpha.2 <0.3.0`，没有增加新的兼容性声明。保留已验证的 `0.2.1-rc.3`、`0.2.1-rc.2`、`0.2.1-alpha.5`、`0.2.1-alpha.4`、`0.2.1-alpha.3`、`0.2.1-alpha.1`、`0.2.0-rc.2`、`0.2.0-rc.1`、`0.1.7-rc.2`、`0.1.7-rc.1` 与 `0.1.7-alpha.2`。

```sh
dsh plugin --profile web add dsh-update-status@0.4.7
```

升级后重新加载页面。若宿主提示需重启，请在当前任务完成后按提示重启。本次未进行刷新后的真实页面视觉验收；自动化测试覆盖菜单不再注册和默认版本入口仍然注册。

<h3 id="en-v0.4.7">Plugin 0.4.7 — a simpler version-update entry</h3>

### Version matrix

| Plugin | Verified DSH | npm |
| --- | --- | --- |
| `0.4.7` | `0.2.1-rc.3` and the ten previously verified releases | This release, `latest` |

### Why this update and what changed

- **Removes the redundant Settings → Version & updates menu.** Installation already shows version status and update notices by default, and clicking the sidebar version chip opens the details. The separate settings page duplicated that functionality, so its menu, page, dedicated styles and translations are removed to simplify Settings.
- **Version notices and primary actions are unchanged.** The running version, update notices, manual checks, upgrade guidance, cache duration and guarded safe restart remain in the chip's detail panel. The sidebar visibility toggle and service-start-time display belonged only to the removed settings page and are removed with it. No automatic upgrades, automatic restarts or scheduled checks are added.
- **Existing configuration remains compatible.** Upgrading or mounting never rewrites preferences. An older profile with `sidebarEnabled: false` stays hidden; set it to `true` or remove the override to restore default visibility. New installations require no settings-page opt-in.
- **Verification and documentation stay synchronized.** All 219 tests, type checks, build and dependency guard pass. Recovery-guidance rendering tests now exercise the remaining detail panel, and both READMEs are updated.

### Compatibility and upgrade

The DSH range remains `>=0.1.7-alpha.2 <0.3.0`; no new compatibility claims are added. Retains verified `0.2.1-rc.3`, `0.2.1-rc.2`, `0.2.1-alpha.5`, `0.2.1-alpha.4`, `0.2.1-alpha.3`, `0.2.1-alpha.1`, `0.2.0-rc.2`, `0.2.0-rc.1`, `0.1.7-rc.2`, `0.1.7-rc.1` and `0.1.7-alpha.2`.

```sh
dsh plugin --profile web add dsh-update-status@0.4.7
```

Reload the page after upgrading. If the Host asks for a restart, do so after current work finishes. This change has not had a refreshed-page visual acceptance check; automated tests cover the absent settings registration and the default version entry remaining registered.
