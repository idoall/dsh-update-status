第一个版本：在侧栏显示 DSH 当前版本，线上有新版本时给你一条可以自己执行的升级命令。

已验证 DSH `0.1.2-rc.1`。

<h3 id="cn-v0.1.0">✨ 新增</h3>

- **侧栏里的版本芯片**：把品牌行的名称换成 `DeepSeek + 当前版本`，官方鱼标保持不变。侧栏收起时也有一个入口。
- **更新提示**：只读地查 npm 上最新的版本，有更新时给出一条钉在该版本上的命令；插件不会替你安装任何东西。
- **详情面板与设置项**：点芯片可看当前版本、线上版本、是否验证过兼容，以及那条命令；偏好设置直接存在设置页里。

### 升级

```sh
dsh plugin --profile web add dsh-update-status@0.1.0
```

<h3 id="en-v0.1.0">✨ Added</h3>

The first release: show the running DSH version in the sidebar, and hand you a command you can run yourself when a newer version is published.

Verified against DSH `0.1.2-rc.1`.

- **A version chip in the sidebar**: the brand row shows `DeepSeek` plus the running version; DSH's own fish mark stays. There was also an entry in the collapsed rail.
- **An update notice**: it reads the newest version from npm read-only, and shows a command pinned to that version — it never installs anything for you.
- **A detail panel and settings**: tap the chip for the running version, the published version, whether it was verified, and that command; preferences live in Settings.

### Upgrade

```sh
dsh plugin --profile web add dsh-update-status@0.1.0
```
