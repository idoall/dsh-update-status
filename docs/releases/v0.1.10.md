<h3 id="cn-v0.1.10">插件 0.1.10 — 去掉收起侧栏时的多余入口</h3>

从 `0.1.0` 起，插件在收起后的侧栏轨道里还放了一个 ↟ 入口。那条轨道只放得下官方的一个图标，再挤一个就会溢出去：手机等窄屏上侧栏默认就是收起的，相邻插件的图标被推出屏幕左缘，本插件的状态点压到了轨道边框上。本版取消这个入口。

兼容最新 DSH `0.1.7-rc.2`（同时覆盖 `0.1.7-rc.1`、`0.1.7-alpha.2`），已验证清单与 `0.1.9` 相同；仍在使用更早 DSH（含 `0.1.6-alpha.2`）的人请继续留在插件 `0.1.5`。

### ⚠️ 调整

- **收起侧栏时不再显示任何入口。** 入口只剩展开后品牌行里的版本芯片；要打开面板，展开侧栏点一下芯片即可，面板内容、数据与命令都没有变化。
- **设置页的说明同步改了口径**，偏好字段与存储方式完全没动，升级不需要迁移。
- **官方那个图标重新回到居中位置**，不会再被顶偏。

### 升级

```sh
dsh plugin --profile web add dsh-update-status@0.1.10
```

本次只改客户端半边，升级后刷新页面即生效。

<h3 id="en-v0.1.10">Plugin 0.1.10 — the collapsed sidebar loses an extra entry</h3>

Since `0.1.0` the plugin also put a ↟ entry into the collapsed sidebar rail. That rail has room for exactly one official icon and no more: on a phone — where the sidebar is collapsed by default — the neighbouring plugin's icon was pushed off the screen's left edge and this plugin's status dot ended up on the rail's border. This release drops the entry.

Verified against DSH `0.1.7-rc.2` (also `0.1.7-rc.1`, `0.1.7-alpha.2`); the verified list is the same as `0.1.9`. On an older DSH — including `0.1.6-alpha.2` — stay on plugin `0.1.5`.

### ⚠️ Changed

- **A collapsed sidebar now renders nothing extra.** The only entry left is the version chip in the expanded brand row; to open the panel, expand the sidebar and click the chip — its contents, data and commands are unchanged.
- **The settings description follows**, while the preference fields and their storage are untouched, so upgrading needs no migration.
- **The official icon is centred again** instead of being pushed aside.

### Upgrade

```sh
dsh plugin --profile web add dsh-update-status@0.1.10
```

This release only changes the client half, so refresh the page after upgrading.
