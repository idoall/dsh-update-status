<h3 id="en-v0.3.2">🎨 Improved</h3>

A documentation-only release: the README's version notes and every past release note are now written in plain language. No code changed — this behaves exactly like 0.3.1.

Verified against DSH `0.2.1-alpha.1`; the verified list is the same as `0.3.1`.

- **The version table is readable now.** Each row went from a few hundred characters of implementation detail to one sentence: what that version did, and whether it is worth upgrading to.
- **Every historical release note was rewritten.** Sixteen versions, the longest from 266 lines down to about 50; they only describe changes you can notice, with the upgrade command at the end.
- **Nothing behaves differently.** Upgrading changes no behaviour and needs no migration.

### Upgrade

```sh
dsh plugin --profile web add dsh-update-status@latest
```
