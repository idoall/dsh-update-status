<h3 id="cn-v0.2.0">插件 0.2.0 — 一条发布线：只显示当前版本，有更新才提示</h3>

一次界面简化：取消「发布通道」，插件自己从 npm 上所有已发布版本里挑出最新的那个，你只需要看有没有更新。

兼容的最新 DSH 版本：`0.2.1-alpha.1`；清单里还保留 `0.2.0-rc.2`、`0.2.0-rc.1` 和更早的 `0.1.7` 系列。

### ⚠️ 调整

- **不用再选发布通道**：稳定版、RC、Alpha 放在一起比较，谁最新就提示谁。以前跑在稳定版前面的预发布版，要你先手动切换通道才会出现。
- **面板只剩一条结论**：打开就是当前运行版本，加上「已是最新」或「发现新版本 `X`」；通道列表和每行的兼容性标签都删掉了。
- **「设置 → 版本与更新」同步瘦身**：只保留「在侧栏显示版本状态入口」一个开关，原来的通道下拉框和预览版升级说明都不见了。
- **以前配置里留下的通道项不会出问题**：插件照常加载，那一项只是不再起作用，可以从配置里删掉。

### ✨ 新增

- **有更新时给出一条可以照着敲的命令**，钉在确切版本上，而不是 `@latest` 这种会移动的标签；插件只负责显示和复制，不会替你执行。

### 升级

```sh
dsh plugin --profile web add dsh-update-status@0.2.0
```

升级后请刷新 Web GUI。本插件仍然不会安装、重启、回滚或替换任何文件。

<h3 id="en-v0.2.0">Plugin 0.2.0 — one release line: it shows your running version and speaks up only when something newer exists</h3>

An interface simplification: the release-channel idea is gone, and the plugin picks the newest version published on npm by itself.

Verified against DSH `0.2.1-alpha.1`; the list also keeps `0.2.0-rc.2`, `0.2.0-rc.1` and the earlier `0.1.7` releases.

### ⚠️ Changed

- **There is no channel to select.** Stable, release candidate and alpha are compared together and you hear about whichever is newest; a prerelease running ahead of the stable line used to appear only after you switched channels by hand.
- **The panel is down to one verdict**: the version you are running, plus either "up to date" or a newer version `X`. The channel list and the per-row compatibility labels are gone.
- **Settings → Version & updates follows the same shape** and keeps only the "show the version-status entry in the sidebar" toggle; the channel dropdown and the preview-upgrade notes are gone.
- **A leftover channel entry in your configuration is harmless.** The plugin still loads, that entry simply does nothing, and you can delete it.

### ✨ Added

- **When an update exists, you get one command you can run**, pinned to the exact version instead of a moving tag such as `@latest`. The plugin only shows and copies it; it never runs anything for you.

### Upgrade

```sh
dsh plugin --profile web add dsh-update-status@0.2.0
```

Refresh the Web GUI after upgrading. The plugin still never installs, restarts, rolls back or replaces any file.
