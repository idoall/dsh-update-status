<h3 id="cn-v0.1.4">插件 0.1.4 — 正在运行的通道不再被隐藏</h3>

修掉一个「正在运行的那条通道反而选不了」的死锁：如果 DSH 跑的正是某个通道发布的版本，那一行会从面板和设置页里消失。这次也说明了此前「我的偏好自己变了」是怎么回事。

已验证 DSH `0.1.6-alpha.1`（同时覆盖 `0.1.5-rc.1`）。

### 🐛 修复

- **正在运行的通道不再消失**：只有前一行已经显示了同一个版本号时才会隐藏；如果所有通道都指向正在运行的版本，仍然只保留一行。
- **偏好不是插件自己改的**：能写关注通道的只有面板上的「选择此通道」按钮和设置页的下拉框，两处都要你亲手点。当时面板里唯一还能点的另一行是稳定版，点了确实会切过去——现在不会再出现这种「只剩一个选项」的局面。

### 升级

```sh
dsh plugin --profile web add dsh-update-status@latest
```

如果你之前因为面板里看不到 `alpha` 而把关注通道改成了稳定版或 `next`，现在可以重新选回 `alpha`。插件依旧只读。

<h3 id="en-v0.1.4">Plugin 0.1.4 — the channel you are running stays selectable</h3>

Fixes a deadlock where the channel you were actually running could not be selected: if DSH was running a release published on a channel, that row vanished from both the panel and the settings page. It also explains an earlier "my preference changed by itself" report.

Verified against DSH `0.1.6-alpha.1` (also `0.1.5-rc.1`).

### 🐛 Fixed

- **The channel you are running no longer disappears.** A row is hidden only when an earlier row already shows the same version; when every channel points at the running release, the list still collapses to one row.
- **The plugin never changed the preference on its own.** Only two things can write the followed channel — the per-channel button in the panel and the select on the settings page — and both need your click. Back then the only other selectable row was the stable channel, and clicking it really did switch you there; that dead end is gone.

### Upgrade

```sh
dsh plugin --profile web add dsh-update-status@latest
```

If you switched to the stable channel or `next` earlier because `alpha` was not listed, you can pick `alpha` again now. Still read-only.
