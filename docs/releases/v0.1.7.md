<h3 id="cn-v0.1.7">插件 0.1.7 — 告警开始跟着界面语言走</h3>

`0.1.6` 解决的是「在 DSH 0.1.7 上能不能用」，这一版解决「说不说人话」：以前英文界面里会冒出中文告警，现在按页面自己的语言显示。改动来自社区贡献（[@ivkiwi](https://github.com/ivkiwi) 的 PR #7）。

兼容最新 DSH `0.1.7-rc.1`（同时覆盖 `0.1.7-alpha.2`）；仍在使用更早 DSH（含 `0.1.6-alpha.2`）的人请继续留在插件 `0.1.5`。

### 🐛 修复

- **英文界面里不再出现中文告警。** 告警句子以前由宿主拼好、页面原样显示；现在宿主只给出与语言无关的事实，措辞由页面按当前语言渲染。
- **新旧版本混装也有兜底。** 新客户端配旧宿主、或旧客户端配新宿主时，仍会显示一句有用的英文，而不是一片空白。
- **安装引导同样本地化了**，但真实的升级命令（`npm install -g …` / `pnpm add -g …`）原样透传——命令永远不会被翻译改坏。

### 升级

```sh
dsh plugin --profile web add dsh-update-status@0.1.7
```

宿主半边只在 DSH 启动时加载，所以升级后**需要重启 `dsh web`**；客户端半边刷新页面即生效。从 `0.1.6` 升级不需要任何迁移。

<h3 id="en-v0.1.7">Plugin 0.1.7 — warnings now follow the page language</h3>

`0.1.6` was about whether the plugin worked at all on the DSH 0.1.7 line; 0.1.7 is about whether it speaks your language — an English UI used to show Chinese warnings, and now every warning follows the page. Contributed by [@ivkiwi](https://github.com/ivkiwi) in PR #7.

Verified against DSH `0.1.7-rc.1` (also `0.1.7-alpha.2`); on an older DSH — including `0.1.6-alpha.2` — stay on plugin `0.1.5`.

### 🐛 Fixed

- **No more Chinese text inside the English UI.** The Host used to build the warning sentence and the page printed it as-is; now the Host states the bare fact and the page words it in the language you are reading.
- **Mixed versions still get a sentence.** A new client against an older Host, or the other way round, still shows a useful English line instead of nothing at all.
- **Install guidance is localized too**, while real upgrade commands (`npm install -g …` / `pnpm add -g …`) pass through untouched — a command can never be broken by translation.

### Upgrade

```sh
dsh plugin --profile web add dsh-update-status@0.1.7
```

The Host half loads when DSH starts, so **restart `dsh web`** afterwards; the client half takes effect on a page refresh. Upgrading from `0.1.6` needs no migration.
