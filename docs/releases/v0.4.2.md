DSH `0.2.1-alpha.3` 不需要功能改动；本版只将它列为已验证兼容，面板不再显示「尚未验证兼容」。

兼容最新 DSH `0.2.1-alpha.3`；已验证清单仍保留 `0.2.1-alpha.1`、`0.2.0-rc.2`、`0.2.0-rc.1`、`0.1.7-rc.2`、`0.1.7-rc.1` 与 `0.1.7-alpha.2`。

<h3 id="cn-v0.4.2">⚠️ 调整</h3>

- **没有功能代码改动。** peer 范围 `>=0.1.7-alpha.2 <0.3.0` 已接纳 alpha.3，profile 加载不会跳过插件。
- **已核对当前运行时。** 状态 RPC、设置表单、侧栏品牌槽、浮层和设置页槽保持可用；一次性 profile 的 `--dump-config` 也无兼容拒绝。
- **升级后的可见变化只有一项。** 当前运行的 `0.2.1-alpha.3` 会显示为已验证兼容，而不是提示尚未验证。

### 升级

```sh
dsh plugin --profile web add dsh-update-status@latest
```

---

DSH `0.2.1-alpha.3` needs no functional code change; this release only marks it verified, so the panel no longer says *compatibility unverified*.

Verified against the current DSH `0.2.1-alpha.3`; the list also keeps `0.2.1-alpha.1`, `0.2.0-rc.2`, `0.2.0-rc.1`, `0.1.7-rc.2`, `0.1.7-rc.1` and `0.1.7-alpha.2`.

<h3 id="en-v0.4.2">⚠️ Changed</h3>

- **No functional code changed.** The peer range `>=0.1.7-alpha.2 <0.3.0` already admits alpha.3, so profile loading does not skip the plugin.
- **The live runtime was audited.** The status RPC, settings form, sidebar-brand slot, overlay and settings-section slot remain available; an isolated profile's `--dump-config` also had no compatibility refusal.
- **There is one visible upgrade effect.** The running `0.2.1-alpha.3` is now shown as verified compatible instead of compatibility unverified.

### Upgrade

```sh
dsh plugin --profile web add dsh-update-status@latest
```
