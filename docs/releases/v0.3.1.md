0.3.0 的一次小补丁：把「重启」这件事在两个界面上都讲清楚，并让会中断的任务列表更好读。功能与 0.3.0 完全一致，升级不需要做任何事。

兼容最新 DSH `0.2.1-alpha.1`；已验证清单与 `0.3.0` 相同。

<h3 id="cn-v0.3.1">🎨 优化</h3>

- **设置页也写明了重启的前提**：以前只有面板底部那句「只有装好用户级服务才允许安全重启」，现在设置页的重启按钮旁边也有同样的说明。
- **任务列表不再把按钮挤走**：会中断的列表里如果有一条很长的命令，最多显示两行，确认和取消按钮始终看得见。
- **新增一页[在 Linux 或 Windows 上自己验证](docs/platform-acceptance.md)的步骤**：这两个系统的服务定义已经生成并有测试覆盖，但还没真机验过；照那三步走就能确认，出问题该看哪里也写在里面。

### 升级

```sh
dsh plugin --profile web add dsh-update-status@latest
```

刷新 Web GUI 即可，没有别的要做的。

[中文](#cn-v0.3.1) | [English](#en-v0.3.1)

<h3 id="en-v0.3.1">🎨 Improved</h3>

A small patch for 0.3.0: the same explanation now appears wherever Restart does, and the list of work it would interrupt stays readable. Nothing below the surface changed — upgrading needs no action.

Verified against the current DSH `0.2.1-alpha.1`; the verified list is the same as `0.3.0`.

- **Settings explains restart too**: the "only when a user-level service supervises DSH" line used to appear only at the bottom of the panel; the settings page now carries it next to the button as well.
- **A long command can no longer push the buttons away**: list entries are clamped to two lines, so Confirm and Cancel stay visible.
- **New page: [verifying on Linux or Windows](docs/platform-acceptance.md)**. Those two systems' service definitions are generated and covered by tests but have not been run for real yet; that page is the three-step way to check, including where to look if something is off.

### Upgrade

```sh
dsh plugin --profile web add dsh-update-status@latest
```

Refresh the Web GUI; nothing else to do.
